# Synode TRELLIS.2 iframe

Embed this app into any website using an iframe.

```html
<iframe
  src="https://YOUR-DOMAIN/embed"
  title="Synode Image to 3D"
  style="width: 100%; height: 100vh; border: 0"
  allow="fullscreen"
></iframe>
```

**Language** — default is English. Add `?locale=fr` for French:

```html
<iframe src="https://YOUR-DOMAIN/embed?locale=fr" ...></iframe>
```
